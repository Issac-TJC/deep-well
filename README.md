# Deep Well Web build

Playable release exported from the current local Godot project with Godot 4.7.2 Standard.

This branch contains only the published Web build. The original HTML5 source remains on `master`.
The Godot source snapshot includes local changes not yet committed to `master`; see `build-info.json` for build hashes.

Single-threaded Web export; no cross-origin isolation headers are required. PWA/service worker is disabled.

Game: https://issac-tjc.github.io/deep-well/
