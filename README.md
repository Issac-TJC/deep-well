# 🐰 Deep-Well

> An atmospheric puzzle-platformer inspired by the masterpiece **Animal Well**.

## 📖 About The Project

Hi there! I really enjoy playing **Animal Well**—it is one of my all-time favorite games. Inspired by its eerie atmosphere and intricate puzzles, I am building my own **Animal Well-like game** using pure HTML5 and JavaScript.

This is a passion project where I explore game development mechanics, pixel art, and atmospheric sound design. I hope you enjoy playing it as much as I enjoy building it!

## 🎮 How to Play

1.  Clone this repository.
2.  Open `index.html` in your browser.
3.  Use **Arrow Keys** to move and **Space** to jump.
